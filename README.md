

# Crystal Detection & Tracking Pipeline

A computer vision pipeline for detecting, tracking, and embedding crystal instances in video footage using YOLO, DeepSORT, and a ResNet50-based metric learning model.

https://github.com/user-attachments/assets/2cbe068c-707e-484c-a7a9-d23a13689cd4

---

## Project Overview

This project provides three main components:

1. **Frame Extraction** — Extract frames from a video for annotation and training
2. **YOLO OBB Training & Tracking** — Detect crystals using an oriented bounding box (OBB) YOLO model and track them across frames with DeepSORT
3. **Embedding Model Training** — Train a ResNet50-based embedding network using cosine similarity loss for instance-level crystal recognition

## Usage

### 1. Extract Frames from Video

Extracts every frame from a video and copies every 100th frame to a `KeyFrames/` folder for manual annotation.

```bash
python get_frames.py
```

- Set `video_filename` inside the script to point to your video
- Annotated keyframes should be labelled using a tool such as [Roboflow](https://roboflow.com) or [LabelImg](https://github.com/heartexlabs/labelImg) with OBB support
- Output: `VideoinFrames/` (all frames), `KeyFrames/` (sampled frames)

---

### 2. Train YOLO OBB Model

Trains a YOLO oriented bounding box model on your labelled crystal dataset.

```bash
python tracker_standard.py
```

- Requires a `config.yaml` YOLO dataset config file pointing to your labelled data
- Training runs for 200 epochs on CUDA by default
- Checkpoints are saved under `runs/obb/`

---

### 3. Run Crystal Tracking (OBB)

Runs the trained OBB YOLO model on extracted frames and tracks individual crystals using DeepSORT. Annotated frames are compiled into an output video.

```bash
python tracker_obb.py
```

- Update the YOLO model path (`best.pt`) and frame directory inside the script
- Output frames and `video.mp4` are saved to `SavedFramesYolo/`

**Key DeepSORT parameters:**

| Parameter | Value | Description |
|---|---|---|
| `max_cosine_distance` | 0 | Strictest appearance matching |
| `n_init` | 15 | Frames before a track is confirmed |
| `max_age` | 120 | Frames a track is kept without a detection |

---

### 4. Train ResNet50 Embedding Model

Trains a metric learning model that maps crystal images to a 512-dimensional embedding space using cosine embedding loss. Positive pairs are generated by applying two random augmentations to the same image.

```bash
python train_resnet50_cosine.py \
    --data-root ./path/to/crystal/images \
    --out-dir checkpoints_cosine \
    --epochs 30 \
    --batch-size 32 \
    --lr 1e-2 \
    --embed-dim 512
```

**Arguments:**

| Argument | Default | Description |
|---|---|---|
| `--data-root` | *(required)* | Folder of individual crystal images |
| `--out-dir` | `checkpoints_cosine` | Directory for saved checkpoints |
| `--epochs` | 30 | Number of training epochs |
| `--batch-size` | 32 | Batch size |
| `--lr` | 0.01 | Initial learning rate (SGD) |
| `--embed-dim` | 512 | Output embedding dimension |
| `--save-every` | 5 | Checkpoint save frequency (epochs) |

Checkpoints are saved as `cosine_epoch{N}.pth`.

## Model Architecture

### EmbeddingNet (ResNet50)

- **Backbone:** Pretrained ResNet50 (convolutional layers only, pooling and FC removed)
- **Pooling:** AdaptiveAvgPool2d → (B, 2048)
- **Projection:** Linear(2048 → embedding_dim)
- **Normalization:** L2-normalized output embeddings
- **Loss:** `nn.CosineEmbeddingLoss` with margin 0.0

Augmentations during training include random rotation (0–360°), random crop (224×224), and random horizontal flip.

## Notes

- The OBB tracker (`tracker_obb.py`) expects YOLO OBB results (`results[0].obb`); the standard tracker (`tracker_standard.py`) uses axis-aligned boxes (`results[0].boxes`)


- The embedding model's `forward()` method accepts PIL images at inference time and handles preprocessing internally
